# Architecture Decision Records (ADR)

Architekturentscheidungen halten Kontext, Entscheidung, Alternativen und Konsequenzen fest. Die [OpenSpec-Baseline](https://github.com/stritti/nak-district-planner/tree/main/openspec/specs) bleibt verbindlich für das implementierte Verhalten.

- [ADR 0001: Vertrauenswürdige externe Kalenderquellen](0001-external-calendar-sync-trust.md)

Neue Entscheidungen verwenden die [ADR-Vorlage](template.md) und erhalten fortlaufende vierstellige IDs. Ein ADR dokumentiert **warum**, OpenSpec spezifiziert **was** umgesetzt wird.
