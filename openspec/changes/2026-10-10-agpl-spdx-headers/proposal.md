# Introduce AGPL SPDX copyright attribution

Apply machine-readable AGPL-3.0-only and 2026 Stephan Strittmatter copyright comments to maintained sources. Preserve third-party licenses and add a deterministic CI check.

## Scope

- Header migration for maintained Python, Vue, TypeScript, JavaScript, CSS, HTML, shell and migration template files.
- No change to runtime behavior or dependencies.
- Exclude external agent skill content, generated files and vendored third-party code.
